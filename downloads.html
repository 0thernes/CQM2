Local Workstation Quickstart (Windows x64 / Linux / macOS)

git clone https://github.com/0thernes/CQM2.git
cd CQM2
bun install
bun run build:native   # Optional: Compiles Zig, CUDA/DirectML/LevelZero C++20/ASM, Rust, Go
bun run check          # Typecheck + Lint + Test Suite + Production Build
bun run start          # Starts Local Workstation Server on http://127.0.0.1:4200
