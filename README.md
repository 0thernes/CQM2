## Install

### Core Prerequisites
- **Bun** `>= 1.3.0` (`bun --version`)
- **Node.js** `>= 24.0.0` (`node --version`, used for zero-dependency repository & inspection verification scripts)
- **Git** `>= 2.40`

### Optional Local Native Hardware Accelerators (Auto-Detected)
- **Zig** `0.17.0` (`zig/src/root.zig` -> WASM SIMD128 + native `cqm2_zig.dll`)
- **LLVM Clang++** `>= 20` + Windows SDK + CUDA 12.x (`cqm2_tri_accel.dll` with `cublasSgemmStridedBatched_v2`, DirectML, Level Zero & AVX2 ASM)
- **Rust / Cargo** `>= 1.90` (`cqm2_rust_ledger.dll` Kahan, Merkle, Lemire & BF16-XOR verifier)
- **Go** `>= 1.24` (`cqm2-telemetry-bridge.exe` 1 Hz GPU cache + 20 Hz UDP OSC emitter)
- **uv** `>= 0.9` + Python `>= 3.12` (`python/npu_world_worker.py` OpenVINO NPU + iGPU daemon)

### Clean-Machine Setup
```bash
git clone https://github.com/0thernes/CQM2.git
cd CQM2
bun install --frozen-lockfile
bun run build:native   # Optional on hosts without native C++/Zig/Rust/Go toolchains
bun run check
```

## Usage

### 1. Launch Standalone Native Windows 11 Workstation (`CQM2.exe`) or Browser Server
Double-click **`CQM2.exe`** (from `native/bin/CQM2.exe`, Desktop, Start Menu, or Taskbar after running `scripts/install-windows-launcher.ps1`) to launch the **standalone 4K OpenGL 3.3 + Jolt Physics 5.5.0 + Dear ImGui + Quad-Silicon workstation directly** (zero `bun` or browser runtime required!). To optionally run the Universal Browser / OpenAPI v1 HTTP server:
```bash
bun run start
```
Open `http://127.0.0.1:4200` in your browser (`Space` toggles play/pause, `1`–`7` switches workspaces, `Ctrl+K` opens the Command Palette, and `/api/v1/openapi.json` serves the OpenAPI 3.1.0 specification).

### 2. Build Static Universal Browser Edition (`site/`)
```bash
bun run pages
```

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| `NPU worker unavailable` | OpenVINO Python worker not cached or host has no Intel AI Boost NPU | Run `uv run --with openvino --with numpy python python/npu_world_worker.py --probe`; CQM2 automatically falls back to Zig SIMD128 with zero downtime. |
| `415 UNSUPPORTED_MEDIA_TYPE` on custom `POST` | Missing `Content-Type: application/json` header on JSON mutation | Include `-H "Content-Type: application/json"` on all `POST` / `PATCH` calls to `/api/v1/*`. |
| `SharedArrayBuffer` inactive on `file://` | Browser requires `COOP/COEP` isolation headers | Run `bun run start` (`http://127.0.0.1:4200`), which attaches `COOP: same-origin` and `COEP: require-corp`. |
| PowerShell path error inside `[Vibe Coded (AI)]` | PowerShell treats `[` and `]` as glob wildcards | Always pass `-LiteralPath` in PowerShell cmdlets. |
